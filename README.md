## 使用说明

1. 在 `tools/` 目录下找到需要的工具，点击文件后选择 “Download raw file” 下载。
2. 使用 Microsoft Excel（或 WPS / LibreOffice Calc）打开。
3. 含宏的 `.xlsm` 文件需在打开后选择“启用内容”才能正常使用。
