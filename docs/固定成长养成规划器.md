# 固定成长 · 养成规划器 使用说明

文件：[`tools/固定成长养成规划器.xlsx`](../tools/固定成长养成规划器.xlsx)

## 工作表

| Sheet | 作用 |
| ---- | ---- |
| 养成规划 | 主页面：选角色、填起点/目标，给出转职路线、熟练度提示、实战评估和逐级成长表 |
| 角色成长率 | 角色数据：个人成长率、初始等级与能力值（不含兵种基础值）、初始技能等级、擅长/弱项、特技等 |
| 职业 | 职业数据：成长率补正、兵种基础能力值、限定（女性专用/角色专用）、转职条件原文及解析出的所需熟练度、可用武器、精通加成 |

## 使用步骤

1. **① 角色**：B4 下拉选角色。第 8 行「资料初始值」显示角色表里的初始等级、兵种和面板能力（个人能力 + 兵种基础值），可以照抄到起点。
2. **起点 / 目标**：填等级、职业、9 项面板属性。起点职业留空 = 初始兵种；目标属性留空 = 不作要求。
3. **⑦ 实战评估参数**（右上）：敌方速度、物理/魔法攻击、防守、魔防；我方攻击类型 / 速度定位 / 前排定位（默认「自动」）；是否计入兵种基础值。
4. **② 武器熟练度**：填游戏里当前的熟练度（留空 = 角色初始值）。
5. **③ 推荐路线 Top5 / ③+ 中途换职优化 Top5**：见下文「推荐算法」。
6. **显示路线**（K14）：默认「自动」：⑤手动路线填了内容就显示手动，否则显示推荐 1。也可以指定 推荐1~5 / 优化1~5 / 手动。
7. **④ 当前显示路线**（最多 10 段）：每段的转职等级、升级次数、所需熟练度、熟练度提示、转职/解锁条件。
8. **最终属性对比 + 实战评估**：实战评估区第一行可以填**我方武器威力、重量**，评估结果和推荐排序都会立即重算。
9. **⑤ 手动路线**（10 段）：按等级从上往下填「转职等级 + 职业」，逐级表、最终属性、实战评估会同步联动。
10. **⑧ 自动推荐候选职业**：每个职业一个复选框，点一下勾选/取消，勾选 = 参与计算；右侧按系列（斗士系、猎兵系、士兵系、魔道系、飞行系）一键开关。标题实时显示当前参与推荐的职业数。起点和目标职业不受限制。
    - 复选框需要 Microsoft 365 版 Excel（Windows / Mac / 网页版）。旧版 Excel、WPS 里显示为 TRUE / FALSE，直接改写即可。
11. **⑥ 逐级成长表**：逐级显示职业和面板属性。

## 规则

### 属性成长（固定成长）
- 每升 1 级，各属性经验槽 +（角色成长率 + 当前职业补正）。每级增量最低按 0 计，不会倒扣；满 100 属性 +1。
- 「初始经验槽%」默认 0，是最保守的算法。

### 兵种基础能力值
- 面板属性 = 个人能力 + 当前兵种基础值（数据源注明角色初始能力「去除兵种基础等赋予值」）。
- 换职业时，面板按两个职业的基础值差变化。最终属性按目标（最后）职业的基础值计算，逐级表也按每一级所在职业显示。
- 部分职业（重装骑兵、战象兵、多数最上级 / 神将职）基础值暂缺，按 0 计。⑦ 里「计入兵种基础值」选「否」可以关掉。

### 精通加成
- 职业表「精通加成属性 / 值」：在该职业累计练满「精通需练级数」（I13，默认 5 级）即计入。目前只有 **天翼兵 魔防+3**。

### 实战评估
- **体格** = INT(力量 / 5)；**攻速** = 速度 − MAX(0, 武器重量 − 体格)。
- **速度**：高速定位要求 攻速 ≥ 敌速 + 4（能追击）；低速定位要求 敌速 − 攻速 < 4（不被追击）。
- **攻击**：力量或魔力 + 武器威力 > 敌方防守或魔防，即为破甲。
- **前排**：防守 ≥ 敌物攻 − 5，魔防 ≥ 敌魔攻 − 5。
- 「自动」定位：
  - 攻击类型：看目标职业下的力量 / 魔力成长哪个高。
  - 前排：目标职业属于重装。
  - 速度：前排按低速；否则速度成长 ≥ 50 为高速。

### 职业限定
- 女性专用职业（天翼兵、圣天翼兵）只对女性角色（及自选性别的主角）推荐。
- 舞者只对蕾达推荐。

### 熟练度提示
- 转入某职业时，所需熟练度要么已经达到，要么能在之前待过的职业里练。「能练」指那个职业的「可使用的技能」有这种武器，且角色该项不是 ×。
- 只作提示，不参与排序。

## 推荐算法

- **推荐**：在节点等级（5 / 20 / 35 / 45）之间，每个区间选一个职业，穷举全部组合（最多 6000 个）。
  - 候选职业：已勾选 + 系列已勾选 + 符合性别/角色限定 + 已达到最低转职等级。
  - 设置了目标职业时，最后一段固定为目标职业。
- **优化**：在推荐 1 的某个区间中途再换一次职业，枚举换成哪个职业、第几级换。换职前后两段各至少练 B13 级（默认 3）。
- **排序**：达成项多 ＞ 实战评估通过多 ＞ 缺口小 ＞ 力/魔高 ＞ 属性总和大。

### 重算
- 文件设置为「自动计算 + 每次全表重算」：改任何输入、勾选后，推荐 / 优化 / 逐级表 / 评估都会立即更新（公式较多，需要几秒）。
- 如果改动后没有变化，检查 Excel「公式 → 计算选项」是否为「自动」，或按 F9 手动重算。

## 数据更新

数据源是玩家整理的 Excel（两个 sheet：「01-全可加入角色信息」「02-兵种职业信息」）。数据源有更新时：

```bash
python scripts/import_source.py 数据源.xlsx   # 生成 data/characters.csv、data/classes.csv
python scripts/build_growth_planner.py        # 生成 tools/固定成长养成规划器.xlsx
```

- 转职条件原文（如「枪术/斧术任意一项C&重装术E+、道具…」）会自动解析成「必需 / 满足其一」的熟练度要求。
- 「--」按初始 E 处理；没有成长率数据的 NPC 不收录。
- 精通加成、默认不勾选的职业写在 `scripts/import_source.py` 开头，可以按需补充。
