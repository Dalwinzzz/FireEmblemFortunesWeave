# 固定成长 · 养成规划器 使用说明

文件：[`tools/固定成长养成规划器.xlsx`](../tools/固定成长养成规划器.xlsx)

## 工作表

| Sheet | 作用 |
| ---- | ---- |
| 养成规划 | 主页面：选角色、填起点/目标和熟练度，给出转职路线、熟练度检查和逐级成长表 |
| 角色成长率 | 原始数据：角色个人成长率、初始武器熟练度（可直接订正） |
| 职业 | 原始数据：职业补正、使用武器、转职所需熟练度、解锁条件，外加「最低转职等级」「纳入推荐」两列（可直接订正/追加） |

## 使用步骤

1. **① 角色**：B4 下拉选角色，填起点和目标的等级、职业、9 项属性。目标属性留空 = 不作要求。
2. **② 武器熟练度**：第 20 行填游戏里当前的熟练度（下拉选 E~S，× 表示无法习得）。留空就用角色表里的初始值，没有数据按 E 算。
3. **③ 推荐路线 Top5**：每个区间（5/20/35/45 级为节点）选一个职业，穷举全部组合。
4. **③+ 中途换职优化 Top5**：在推荐 1 的基础上，挑一个区间在中途再换一次职业，枚举换成哪个职业、在第几级换。同一区间的同一职业只保留最优的换职等级；「换职最少练级」（B13，默认 3）限制换职前后两段都至少练这么多级。
5. **显示路线**（K14）：在 推荐1~5 / 优化1~5 / 手动 之间切换。
6. **④ 当前显示路线**：每段写明几级转什么职业、升几级，右侧三列：
   - **所需熟练度**：职业表里的「转职·主要技能」（全部满足）和「转职·选择技能」（满足其一）。
   - **熟练度检查**：✓ 满足 ／ 需练（之前待过的职业能用这种武器，可以先练上去）／ ✗ 无法满足（之前的职业都用不了这种武器，或该熟练度为 ×，路线不成立）。
   - **解锁条件**：考试票证、推荐等级、名声等级，以及特殊解锁条件。
7. **⑤ 手动路线**：自己填「转职等级 + 职业」验证任意路线，同样带熟练度检查。
8. **⑥ 逐级成长表**：逐级列出所在职业和各项属性。绿色 = 该级属性 +1，黄色行 = 转职。

## 规则

### 属性成长（固定成长）
- 每升 1 级，各属性经验槽 +（角色成长率 + 当前职业补正）。每级增量最低按 0 计，不会倒扣。经验槽满 100 属性 +1，余数继续累积。
- 在某等级转职后，从这一级开始的升级都按新职业补正计算。
- 「初始经验槽%」默认 0，是最保守的算法。

### 转职等级
- 初级 5、中级 20、上级 35、最上级 45（暂定）、神将 45（暂定）。在职业表「最低转职等级」里可以改。

### 熟练度可行性
- 转入某职业时，所需熟练度要么当前已经达到，要么能在**之前待过的职业**（含起点职业）里练：那个职业的「使用武器」里有这种武器，且角色该项熟练度不是 ×。
- 回到已待过的起点职业、或沿用同一职业，不重复检查。
- 只检查“能不能练”，不计算要打多少场才练得上去（没有熟练度经验数据）。

### 推荐排序
依次比较：熟练度无法练成的项数少 ＞ 目标达成项数多 ＞ 不含「靠后」职业 ＞ 缺口合计小 ＞ 最终属性总和大。

### 纳入推荐
职业表「纳入推荐」有三个值：
- **是**：参与推荐。
- **靠后**：参与推荐，但同等条件下排在其他路线后面。舞者、飞天女神将默认是这个值。
- **否**：不参与自动推荐，手动路线仍可选。

## 已知限制

- 暂未考虑：属性上限、转职时职业基础值的变化、熟练度练满需要的时间。
- 很多角色的初始熟练度数据缺失，按 E 计算，建议在 ② 填实际值。
- 内森的成长率数据缺失，按 0 计算。
- 表里公式较多，修改输入后 Excel 重算需要几秒。

## 重新生成

改完 `data/*.csv` 后执行 `python scripts/build_growth_planner.py`。
