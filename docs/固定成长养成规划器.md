# 固定成长 · 养成规划器 使用说明

文件：[`tools/固定成长养成规划器.xlsx`](../tools/固定成长养成规划器.xlsx)

## 工作表

| Sheet | 作用 |
| ---- | ---- |
| 养成规划 | 主功能页：选角色、填起点/目标，给出转职路线和逐级成长表 |
| 角色成长率 | 原始数据：角色个人成长率（可直接订正） |
| 职业 | 原始数据：职业成长率补正，外加「最低转职等级」「纳入推荐」两列（可直接订正/追加） |

## 使用步骤

1. **① 角色**：在 B4 下拉选择角色。
2. **起点 / 目标**：填等级、职业和 9 项属性。目标属性留空 = 不作要求；目标职业留空 = 45 级后沿用上一职业。
3. **③ 推荐路线 Top5**：自动列出 5 条路线，排序依据：达成项数 → 缺口合计最小 → 最终属性总和最大。
4. **显示路线**（K14）：切换「推荐1~5」或「手动」。
5. **④ 当前显示路线**：写明几级转什么职业、在该职业升几级。
6. **⑤ 手动路线**：K14 选「手动」后，自己填「转职等级 + 职业」，验证任意路线。
7. **⑥ 逐级成长表**：逐级列出所在职业和各项属性。绿色 = 该级属性 +1，黄色行 = 转职。

## 计算规则（固定成长）

- 每升 1 级，各属性经验槽 +（角色成长率 + 当前职业补正）。每级增量最低按 0 计，不会倒扣。
- 经验槽满 100，属性 +1，扣掉 100，余数继续累积。
- 升级从 Lv 到 Lv+1 时，按所在职业的补正计算；在某等级转职后，从这一级开始的升级都用新职业的补正。
- 「初始经验槽%」默认 0，是最保守的算法。游戏里实际的初始值未知，一般 ≥ 0，所以实际结果只会等于或好于表中结果。

## 推荐路线的搜索方式

- 推荐路线只在「转职节点等级」（默认 5 / 20 / 35 / 45，对应初级 / 中级 / 上级 / 最上级的推荐等级）换职业，每个区间选一个职业。
- 每个区间只考虑「最低转职等级」≤ 该区间起始等级、且「纳入推荐」= 是 的职业；起点职业总是可以继续使用。
- 设置了目标职业时，最后一段固定为目标职业。
- 在这个模型内会穷举全部组合（最多 6000 个），结果是这个模型下的最优解。想在节点以外的等级转职，就用手动路线验证。

## 数据与已知限制

- 数据来源：用户整理的在线文档（角色成长率、职业两个 sheet），存放在 `data/*.csv`。
- 职业表里没写推荐等级的职业（部分上级 / 最上级 / 神将职），最低转职等级按阶级默认填写；神将职的 45 级是推测值。
- 舞者、飞天女神将默认不纳入推荐（疑似蕾达专属），可在职业表里改。
- 暂未考虑：属性上限、转职时职业基础值的变化、职业解锁条件（名声等级、考试票证、委托等）。
- 内森的成长率数据缺失，按 0 计算。

## 重新生成

改完 `data/*.csv` 后执行：

```bash
python scripts/build_growth_planner.py
```

直接在 Excel 里改「角色成长率」「职业」两张表也会实时生效；但以后重新生成文件时会被 CSV 覆盖，所以请把修正同步到 CSV，或者告诉我。
