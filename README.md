# FireEmblemFortunesWeave

《火焰纹章 万缕千丝》（Fire Emblem: Fortune's Weave）辅助用 Excel 工具合集。

## 目录结构

```
.
├── tools/     # Excel 工具文件（.xlsx / .xlsm）
├── docs/      # 使用说明、数据来源等文档
├── data/      # 原始数据（CSV），生成 Excel 用
└── scripts/   # 生成 Excel 的 Python 脚本
```

## 工具列表

| 工具 | 文件 | 说明 |
| ---- | ---- | ---- |
| 固定成长 · 养成规划器 | [tools/固定成长养成规划器.xlsx](tools/固定成长养成规划器.xlsx) | 选角色、填起点/目标属性，自动给出「几级转什么职业」的养成路线和逐级成长表。[使用说明](docs/固定成长养成规划器.md) |

## 使用说明

1. 在 `tools/` 目录下找到需要的工具，点击文件后选择 “Download raw file” 下载。
2. 使用 Microsoft Excel（或 WPS / LibreOffice Calc）打开。
3. 含宏的 `.xlsm` 文件需在打开后选择“启用内容”才能正常使用。
